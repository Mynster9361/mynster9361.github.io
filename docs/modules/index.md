# PowerShell Modules

A collection of PowerShell modules I've published to the PowerShell Gallery.

## [ActionableMessages](/docs/modules/actionablemessages)

A PowerShell module for creating interactive Actionable Message cards for Microsoft Outlook and other Microsoft 365 applications.

## [LeastPrivilegedMSGraph](/docs/modules/leastprivilegedmsgraph)

A PowerShell module for working with least-privileged Microsoft Graph permissions. *(docs in progress)*
